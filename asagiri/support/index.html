怎么打卡

打开「今天」，先选昨晚到今早有没有晨勃或夜勃，再选 0–4 的硬度自评，然后点底部「完成今天的记录」。其他项（睡眠、饮酒、运动、情绪、用药、备注）都是选填，随时可以回来改。

换设备 / 备份数据

打开「更多 › 备份与恢复」：

  • 「导出数据」生成 Excel 表格，可通过系统分享面板存到「文件」、iCloud 云盘或发给自己；
  • 在新设备上安装 App 后，用「导入数据」选择该表格即可恢复；
  • 当前版本不包含 iCloud 同步，数据只在本机。

忘记密码 / 打不开

如果你开启了「Face ID / 设备密码」解锁，验证用的是系统能力：Face ID 失败可以输入设备密码。若设备没有设置密码，App 会保持锁定——这种情况下只能卸载重装（本地数据会被清除，建议先导出备份）。

提醒没有出现

  • 确认「更多 › 提醒 › 晨间提醒」已打开，且系统「设置 › 通知 › 朝雾」允许通知；
  • 当天已经完成记录时，当天不会提醒；
  • 连续 14 天以上不打开 App，提醒会暂停，重新打开后自动恢复。

数据会不会上传

不会。所有记录只保存在你的设备上，开发者无法访问。详见 隐私政策。

Support (English)

Daily check-in: open Today, choose morning/nocturnal, pick a 0–4 rating, then tap “Complete today’s record”. Everything else is optional.

Backup: More › Backup & Restore. “Export data” creates an Excel file you can save via the share sheet; import it on a new device. The current version has no iCloud sync — data stays on device.

Reminder missing: make sure the reminder is on and notifications are allowed in iOS Settings. The reminder is skipped on days you have already logged, and pauses after 14 days without opening the app.
